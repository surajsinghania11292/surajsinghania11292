### 🌟 Featured Flagship Architecture

#### 🚆 [TrainTravel — Distributed Railway Reservation System](https://github.com/surajsinghania11292/TrainTravel)
*A fault-tolerant, 8-service microservices ticketing architecture designed to handle peak-concurrency ticket reservations with zero double-booking.*

- **Database-per-Service Isolation:** 8 decoupled services (API Gateway, User, Search, Admin, Notification, Booking, Payment, Inventory) backed by PostgreSQL & Prisma.
- **Concurrency Control:** Redis distributed seat locking with TTL auto-expiry and atomic rollbacks to prevent race conditions during flash booking windows.
- **Event-Driven Saga Pattern:** Asynchronous transaction choreography across booking, payment, and inventory via Apache Kafka with Dead-Letter Queue (DLQ) fallbacks.
- **Sub-Second Route Discovery:** Elasticsearch cluster with real-time Kafka index synchronization for instant station and route lookups.
